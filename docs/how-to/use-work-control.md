# How to use Work Control

1. Open the **Work Control** tab below the vanilla Work tab.
2. Filter by pawn name or WorkType; choose whether the Work filter applies to lines, palette, or both.
3. Select one or more pawns in the colonist column.
4. Drag WorkType cards to reorder them, or use `+` to add a capable WorkType.
5. Use `×` on a card to remove it from that pawn's lane.
6. Open **Details** for the first selected pawn to edit schedule, zone focus, overrides and clothing status.

Dropping on a selected group applies the move to the whole selection; dropping outside it affects only the hovered row.

See `docs/reference/work-control.md` for layout and behavior details.
